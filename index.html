无法以本地文件方式运行

这个游戏用了 ES 模块，浏览器出于安全限制，不允许双击 HTML 文件直接打开。
必须通过一个 http 服务访问。任选一种：

方法一 · 本机起个服务（推荐测试用）
在这个文件夹里打开终端，运行：
python3 -m http.server 8080
然后浏览器打开 http://localhost:8080
方法二 · GitHub Pages
把整个文件夹推到 GitHub 仓库 → Settings → Pages → Source 选 main 分支 → 保存，等一分钟即可访问。
方法三 · Firebase Hosting
npm i -g firebase-tools
firebase login
firebase deploy
